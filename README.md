# NEON VORTEX — Arcade Pilot

60초 안에 크리스털을 모으고, 콤보를 쌓고, 보스 **Core Warden**을 격파하는 네온 드론 아케이드 슈터입니다.
순수 HTML/CSS/JavaScript + Canvas 2D로 만들어져 빌드 도구 없이 브라우저에서 바로 실행됩니다.
실행하면 곧바로 게임으로 진입합니다(별도 게임 선택 허브 없음).

## 실행 방법

별도 설치나 빌드가 필요 없습니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 메인 진입점 — `js/` 폴더의 스크립트를 로드 |
| `standalone.html` | 모든 코드가 번들된 단일 파일 버전 — 파일 하나로 어디서나 실행 (생성 산출물) |

```
# 그냥 브라우저로 열거나
start index.html

# 로컬 서버로 실행 (선택)
npx serve .
```

Vercel에 정적 사이트로 배포됩니다 — 메인 게임은 `/`, 단일 파일 버전은 `/standalone.html`에서 제공됩니다.

## 게임 방법

- **목표**: 제한 시간 60초 동안 최대한 높은 점수를 획득
- **조작**: `WASD` / 방향키 — 이동 · **발사는 자동** (가장 가까운 적 조준)
- **모바일 (주 타깃, 세로)**: 화면 어디서나 드래그로 조작. 세로 모드에선 아레나가 90° 회전해 화면 폭을 가득 채웁니다(풀스크린). 홈 화면에 추가하면 앱처럼 실행됩니다(PWA). 피격·보스 격파 시 진동 피드백(일시정지 화면에서 끄기 가능). `⛶` 버튼 또는 게임 시작 시 브라우저 풀스크린 자동 요청
- **체력(HULL)**: ◆ 3칸 — 기뢰·보스 탄막·보스 접촉에 피격 시 1칸 감소, 0이 되면 게임 오버
- **서지(Surge)**: 8초 워밍업 뒤 필드 구간에 예고된 **고강도 서지**가 주기적으로 등장 — 기뢰가 라인 스윕·링 콜랩스·핀서 포메이션으로 몰려옵니다. 서지 사이 소강기에 회복·수집하고, 마지막 20초 보스가 클라이맥스입니다.
- **보스**: 남은 시간 20초에 **CORE WARDEN** 등장 — 격파 시 대량 보너스
- **일시정지**: `ESC` / `P` 또는 우측 상단 `II` 버튼 — 탭 전환·창 비활성 시 자동 일시정지. QUIT TO MENU로 나가면 해당 런은 기록되지 않습니다
- **게임오버 단축키**: `R` / `Enter` — 재시작 · `M` / `ESC` — 메뉴
- 첫 방문 시 조작 안내 화면이 한 번 표시됩니다
- 우측 상단 🔊 버튼으로 음소거 전환

### 게임 모드

메뉴 최상단의 **난이도 칩(EASY / NORMAL / HARD)**이 헤드라인 버튼을 결정합니다:

| 선택 | 헤드라인 | 모드 |
|---|---|---|
| **NORMAL** (기본) | **START DAILY** | UTC 날짜 시드 — 오늘은 전 세계 같은 맵에서 점수 경쟁(공정성을 위해 데일리는 항상 NORMAL). HUD에 베스트와의 실시간 페이스(`+N vs best`) 표시 |
| **EASY / HARD** | **PLAY · {난이도}** | 매번 무작위 시드의 프리플레이를 해당 난이도로 출격 |

데일리는 어떤 난이도를 골랐든 **오늘의 챌린지 브리핑**으로 언제나 진입할 수 있습니다(항상 NORMAL).

난이도는 터렛 수·등장 적 종류·기뢰 속도·보스 HP/사격 속도와 함께 **중반 surge 포메이션 규모**까지 스케일합니다(EASY 0.7× / NORMAL 1.0× / HARD 1.4×). EASY는 터렛·정예 적이 없고 surge가 작으며, HARD는 4종 적 + 더 큰 surge + 탱키한 보스가 등장합니다.

파워업·크레이트 등 **루팅은 넉넉하게** 등장합니다(파워업 화면당 최대 4·약 7초 주기, 크레이트 최대 3·약 5–8초 주기). `보물 항로` 모디파이어에서는 더 후해집니다.

### 런 모디파이어 (Run Modifier)

매 런마다 **STANDARD + 4종** 중 하나의 모디파이어가 적용되어 런의 결을 바꿉니다. **DAILY**는 날짜 시드에서 결정적으로 파생되어 그날은 전 세계가 같은 모디파이어로 플레이하며(브리핑에 미리 표시), **FREE PLAY**는 매 런 무작위로 정해져 시작 시 HUD에 공개됩니다. 모디파이어는 적·구조·루팅·보스만 바꿀 뿐 **점수 계산에는 전혀 영향을 주지 않아**(score-neutral) 리더보드는 날짜·모디파이어와 무관하게 비교 가능합니다.

| 모디파이어 | 결 |
|---|---|
| **기본 / STANDARD** | 변형 없는 기준 런 |
| **기뢰 폭주 / MINE RUSH** | 더 촘촘한 surge + 더 많고 빠른 기뢰 — 군집 생존 |
| **강철 워든 / IRON WARDEN** | 탱키하고 빠르게 쏘는 보스 + 보상 루팅 증가 — 에픽 보스전 |
| **보물 항로 / TREASURE** | 크레이트·파워업 대량 + 적 밀도 감소 — 탐욕 런 |
| **정예 전선 / VANGUARD** | 4종 정예 적 + 추가 터렛 — 적 다양성 |

×2 SCORE 파워업 적용 중에는 모든 점수가 2배가 됩니다.

## 파워업

| 글리프 | 이름 | 효과 | 지속 |
|:---:|---|---|:---:|
| `M` | MAGNET | 주변 크리스털을 끌어당김 | 9초 |
| `S` | SHIELD | 피격 1회 무효화 | 소모형 |
| `T` | SLOW-MO | 적·탄막 속도 감소 | 6초 |
| `×2` | ×2 SCORE | 획득 점수 2배 | 9초 |
| `»` | BOOST | 이동 속도 1.5배 | 8초 |
| `Ψ` | SPREAD | 3방향 발사 | 9초 |
| `+5` | +5 SEC | 남은 시간 +5초 | 즉시 |
| `D` | WINGMAN | 컴패니언 윙맨 6기 편대가 선회하며 자동 사격 (총 화력은 동일) | 9초 |
| `➤` | MISSILES | 적을 추적하는 호밍 미사일 발사 (SPREAD 대체) | 8초 |

같은 파워업을 다시 획득하면 남은 시간에 지속시간이 더해집니다(기본값의 2배까지). 활성 파워업 배지에는 잔여 시간이 숫자와 막대로 표시됩니다.

> 희귀 등장(일반 파워업 풀과 별개로 드물게):
> - `♥` **1UP** — hull을 1 회복(최대 3, 만피 시 SHIELD로 전환).
> - `✸` **BOMB** — 화면의 모든 적 파괴 + 적 탄막 제거(보스·엘리트는 칩 데미지, 격파 불가). 강력한 만큼 1UP보다 더 드물게 등장합니다.
> - `ⓘ` **INTEL** — 희귀 데이터 캐시. 획득 시 즉시 **+250점**(데이터 살베지 계열). 가방 밖 희귀 드롭.

## 기술 노트

- **시드 RNG**: 데일리 챌린지는 `daily-YYYY-MM-DD`(UTC) 문자열을 xmur3 해시 → mulberry32로 변환해 사용합니다. 같은 날짜에는 누구나 동일한 크리스털·적·파워업 배치를 받아 공정한 점수 경쟁이 가능합니다.
- **기록 저장**: 올타임 베스트, 데일리 베스트, 초당 점수 페이스가 IndexedDB(`scoreyard` DB)에 로컬 저장됩니다. 서버 통신은 없습니다.
- **결과 화면**: 점수 출처 브레이크다운(크리스털/콤보/파괴/보스), 초당 점수 추이 스파크라인(데일리는 베스트 런과 겹쳐 비교), 다음 데일리까지 UTC 카운트다운을 표시합니다.
- **데일리 streak·히스토리**: 연속 플레이 일수와 최근 7일 기록을 메뉴에 표시합니다. 별도 카운터 없이 날짜별 `daily_<date>` 키에서 계산합니다.
- **RECORDS 화면**: 홈의 `RECORDS` 버튼 → 올타임 베스트, STREAK, 최근 14일 기록(날짜·점수·보스 클리어)을 한 화면에서 열람합니다(모바일에서 hover 없이).
- **아레나 HUD**: 활성 파워업은 글리프 + 잔여시간 바 배지로, 보스 HP는 상단 막대로 표시됩니다. 체력이 1칸이면 화면 가장자리가 적색으로 맥동하고 피격 시 순간 플래시가 터집니다. 플레이 중 상단은 일시정지 버튼만 두고, 음소거·풀스크린·진동은 일시정지 메뉴에 모았습니다.
- **아레나 데코**: 플레이필드 가장자리에 희미한 시설 데코(헥스 패널·노드·판독 패널)가 깔려 기지 분위기를 냅니다 — 순수 시각 요소로 게임플레이·점수에는 영향이 없습니다.
- **메달 & 랭크**: 런마다 최종 점수로 RANK(RECRUIT→PILOT→ACE→LEGEND)를 매기고, 메달 6종(보스 격파·노히트·플로리스·콤보 ×25·LEGEND·7일 연속)을 판정합니다. 처음 딴 메달은 결과 화면에서 강조되며, 평생 누적 업적은 RECORDS의 ACHIEVEMENTS에서 볼 수 있습니다.
- **테스트**: `node --test "test/unit/*.test.mjs"` (엔진·스토어·정적 검사, 의존성 없음) · `test\run-all.ps1` (단위 + 헤드리스 Edge E2E + 번들 동기화 검사 일괄 실행).
- **결과 공유**: 게임 오버 화면의 `COPY RESULT`로 결과 텍스트를 클립보드에 복사할 수 있으며, 개인정보는 포함되지 않습니다.
- **의존성 없음**: 게임 본체는 외부 프레임워크/CDN 없이 순수 바닐라 JS로 동작합니다(React 불필요). 튜닝 상수는 `js/games/neonvortex/game.js`의 `SY.tweaks` 기본값으로 관리합니다.
- **연출**: CRT 스캔라인 + 비네트 오버레이, 히트스톱(freeze), 화면 흔들림, 파티클 버스트로 레트로 아케이드 타격감을 구현했습니다.
