# ADR-0007: RECORDS 화면 + 아레나 HUD를 DOM 오버레이로

- **상태**: 적용됨 (2026-06-15)
- **관련**: [플랜](../plans/2026-06-15-records-and-arena-ux.md), [ADR-0006](0006-mobile-first-scaled-canvas-unscaled-ui.md)

## Context

세로 모바일 전환 후 두 가지 UX 공백이 드러남:
1. 홈의 7일 기록 셀은 `title` 툴팁으로만 점수를 보여줘 **모바일(hover 없음)에서 점수 확인 불가**.
2. 아레나 안의 정보(효과 표시, 보스 HP)가 캔버스에 그려져 세로 90° 회전 시 옆으로 눕고,
   효과 표시는 작은 텍스트라 한눈에 안 들어옴. 일시정지 버튼은 음소거·풀스크린과 한 모서리에
   몰려 작고 누르기 어려움. 게임 시간도 75→60초로 단축 요청.

## Decision

### RECORDS 전용 화면
- 홈에 `RECORDS` 버튼 → `#screen-records` 오버레이. 올타임 베스트(점수·콤보·날짜·모드) +
  STREAK + 최근 14일 리스트(날짜·점수·보스 ✦). 기존 IndexedDB 데이터(`best_all`,
  `daily_<date>`)만 사용 — 새 영속 스키마 없음. 행 기반이라 hover 없이 모바일에서 점수 열람.

### 아레나 HUD를 DOM으로 (회전 무관 + 가독성)
- **효과 = 타이머 배지**: 글리프 + 잔여시간 바(색상별). 세로에서는 HUD 바와 아레나 사이의
  빈 띠(회전 채움으로 생긴 ~90px 여백)로 이동 — 통계 바와 분리, 버튼과 충돌 없음.
- **보스 HP 바**: `render.js` 캔버스에서 제거하고 상단 DOM(`#boss-hp`)으로. 세로에서 똑바로,
  가독성↑. (캔버스 보스 본체는 유지.)
- **저체력 연출**: HP 1칸에 화면 가장자리 적색 비네트 펄스(`#danger-vignette`),
  피격 순간 적색 플래시(`#hit-flash`). DOM 오버레이라 회전 무관.
- **일시정지/HUD 정리**: 플레이 중 상단은 일시정지 버튼 하나만. 음소거·풀스크린은
  일시정지 메뉴로 이동 → 일시정지 화면이 SOUND·VIBRATION·FULLSCREEN 설정 허브가 됨.

### 시간 60초
- `SY.tweaks.duration` 기본값 75→60. 보스 등장은 `timeLeft<=20 && duration>=40` 기준이라
  자동으로 40초 경과 시 등장(타이밍 로직·점수표 무변경).

## Consequences

- (+) 회전되는 캔버스 안에 더 이상 가독성 핵심 정보(보스 HP)가 없음 — 전부 똑바른 DOM.
- (+) 효과를 한눈에(글리프+바), 저체력 긴박감, 깔끔한 플레이 HUD.
- (+) 엔진(`game.js`) 무변경(시간 상수 제외) — 공정성·시뮬 회귀 위험 최소.
- (−) 세로 상단 띠에 통계 바·효과·보스 HP가 모이므로 위치 조정이 필요했음(효과는 바 아래
  우측, 보스 HP는 그 아래 중앙으로 분리). 좁은 화면에서 동시 표시는 수직 스택으로 해결.
- (−) HUD/배지/보스HP가 매 프레임 `updateHud`에서 갱신(캔버스 핫패스 아님, DOM 쓰기) —
  비네트·플래시는 상태 변화 시에만 토글해 중복 쓰기 회피.

## 테스트
- E2E: RECORDS 열람(ALL-TIME BEST 섹션 + 14일 행), 기존 시나리오 그린(39/39).
- 효과 배지·보스 HP·비네트·일시정지 설정 허브는 rAF 의존이라 Playwright 라이브로 검증
  (헤드리스 가상시간에서 rAF 스로틀 → 스크린샷으로 확인).
- 정적: innerHTML 싱크 핀 3→4(records-body 추가, 값은 fmt/고정 포맷).
