# 아틀라스 매트 제거 (보스 사각 / 모바일 가독성) — 설계

**증상:** `?v=2` 캐시버스트 이후에도 보스가 사각형으로, 아이템 가독성이 모바일에서 저하.

**근본 원인 (픽셀 분석으로 확정):** `assets/sprite-atlas.png`는 **각 스프라이트를
어두운 둥근 카드 위에 그린 스프라이트킷 시트**다. 카드 색은 휘도 ~66 (예: 보스 칸
RGB ≈ 94,47,90). 이전 정리는 순수 검정(임계 28)만 투명화해 이 어두운 카드를 불투명
상태로 남겼다. 어두운 게임 배경에선 카드가 안 보이지만, **흰/밝은 영역·모바일**에선
어두운 사각으로 보인다. 보스 칸은 불투명 픽셀의 75%가 카드였다. → 캐시가 아니라
**아틀라스 알파 자체의 문제**.

소스 확인: `sprite-elements.png`/`ui-kit.png`는 알파 없는 RGB이고 레이아웃도 다름,
`sprite-reference.png`는 알파 전부 255. **깨끗한 대체 소스 없음** → 아틀라스를 직접
정리해야 한다.

**해법:** 경계 시드 flood-fill을 **휘도 임계 T=80**으로 수행 — 검정 + 어두운 카드를
모두 투명화하되, 연결성이 *밝은 테두리로 둘러싸인* 스프라이트 내부의 어두운 영역
(예: 보스의 어두운 적색 코어)은 보존한다. `tools/clean-sprite-atlas.py`에 구현
(재현 가능, 멱등). 사용 중 21개 스프라이트 전부를 흰 배경 합성으로 검증 — 카드 제거,
코어 보존.

**적용:**
- `assets/sprite-atlas.png` 재생성 (투명 69% → 89%).
- 캐시버스트 `?v=2` → `?v=3` (index.html preload + sprites.js sheet.src).
- 정적 테스트는 두 URL 버전 *일치*만 검사 → 자동 통과.

**비고:** 알파는 하드 2단계(부드러운 가장자리 없음)다 — 매트 제거가 우선이라 가장자리
페더링은 범위 밖(선택적 후속). DPR 백스토어(이전 작업)와 합쳐 모바일 선명도는 개선됨.

**미해결(별도):** "아틀라스 풀 활용" — 미사용 스프라이트(함선 변형·젬 색상·적 변형 등)를
게임 요소에 매핑하는 것은 별도 설계로 진행.
