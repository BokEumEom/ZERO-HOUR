# 전체 에셋 활용 로드맵 (Full Asset Utilization)

> **방향 전환(2026-06-29):** 이전의 "자연스럽게만 — 억지 매핑 회피, 잔여 미사용 허용"
> 방침을 폐기하고 **`sprite-atlas.png` + `sprite-elements.png`의 모든 스프라이트를 게임에
> 반영(full utilization)** 하는 것을 표준 방향으로 한다. "억지/forced" 프레이밍은 더 이상
> 사용하지 않는다.
>
> **불변식(유지):** 데일리 공정성 — 게임플레이에 영향을 주는 난수는 시드 `s.rng()`만,
> `Math.random()`은 코스메틱 전용. 신규 시드 소비는 데일리 맵 스트림을 시프트하는
> 버전 변경(시드핀 테스트 재핀 필요할 수 있음).
>
> **금지:** 스폰 포탈(텔레포트)은 이번 세션에 사용자 요청으로 제거됨 — **재도입 금지.**
> 섹션3 텔레포터 화살표는 포탈이 아닌 다른 메커니즘(런치패드/게이트)으로 재해석한다.

## 현황

- **코드에 매핑된 rect(`A`/`POWER_ICONS`/`UI`) 기준:** ~100% 사용 중.
- **시트에 그려진 스프라이트 전체 기준:** ~70% (섹션 2/4의 변형·이펙트 잔여가 갭).
- 이 로드맵은 **시트 기준 100%** 를 목표로 남은 스프라이트를 전부 작업 대상화한다.

## 남은 미사용 스프라이트 인벤토리 → 작업(G1–G6)

각 작업은 별도 design+plan 문서로 분해 후 subagent-driven 실행. fairness 난이도 순(쉬움/안전 → 시드 영향) 정렬.

### G1 — 효과 풀 가동 (섹션 4 EFFECTS 잔여) · *코스메틱, fairness 무관 → 최우선*
미사용: 시안 블레이드/스워시, 대형 틸 워프-링 디스크, 잔해 스펙(debris), 대체 오렌지 폭발.
- **스워시/블레이드** → 플레이어 피격·대시·근접 스파크 연출.
- **워프-링 디스크** → 보스/엘리트/웨이브 등장 시 "워프인" 링(스폰 위치 텔레그래프, 텔레포트 아님).
- **debris 스펙** → 상자/적 파괴 시 파편 파티클(스프라이트 기반).
- **대체 폭발** → 대형 폭발(보스 파트 파괴, BOMB)용 2차 버스트.
- 시드 영향 없음(`Math.random` 코스메틱). 가장 빠르게 닫히는 갭.

### G2 — 위험 텔레그래프 배지 (섹션 6 BOSS/ELITE 잔여) · *코스메틱/표시*
미사용: 경고 삼각형(warning-triangle), 해골-헥스(skull-hex).
- **경고 삼각형** → 엘리트 빔/서지 직전 위치 경고 마커(기존 telegraph 타이밍 재사용).
- **해골-헥스** → 차저(charger) 돌진 예고 또는 보스 위험 페이즈 마커.
- 표시 전용(결정적 상태에서 그림) → fairness 무관.

### G3 — 적 등급 오브 + 메이스 위험체 (섹션 2 ENEMY/HAZARD 잔여) · *시드 영향*
미사용: 크기/색 변형 오브 적 다수, 스파이크 메이스+체인, 핑크 잔해 클러스터, "X" 교차 볼트 노드.
- **오브 등급화** → 소/중/대 오브 적을 틴트·크기로 등급화(분열·점수 차등). elements 시트가 스파이크 오브 위주라 틴트 조합으로 실루엣 구분.
- **메이스+체인** → 회전하며 휘두르는 위험체(swinging hazard, 접촉 데미지, 비파괴 또는 고HP).
- 스폰 위치/개수/등급 = `s.rng` (시드). 신규 시드 소비 = 버전 시프트.

### G4 — 월드 오브젝트 잔여 (섹션 3 INTERACTIVE/WORLD) · *시드 영향*
미사용: 텔레포터-업 화살표, 링/디스크 노드, 글라스-튜브 캡슐 변형.
- **텔레포터-업 화살표** → 아군 "런치 패드/가속 게이트"(밟으면 일시 속도/연사 버프). **포탈 아님.**
- **글라스-튜브/링 노드** → 보급 캡슐 컨테이너 변형(기존 `s.crates` kind 확장, 드롭 테이블 재사용).
- 스폰 = `s.rng` (시드).

### G5 — 환경 위험 + 패널 (섹션 5 ENVIRONMENT/MODULAR 잔여) · *시드/표시*
미사용: 위험-스트라이프 배리어(hazard-stripe), 콘솔 헥스-패널(console-panel).
- **위험-스트라이프** → 아레나 가장자리 위험 띠 또는 주기적 이동 배리어(접촉 데미지).
- **콘솔 헥스-패널** → 추가 콘솔 오브젝트 변형 또는 배경 데코 보강(`drawDecor` 확장).
- 위험체는 시드, 데코는 코스메틱.

### G6 — miniIcon (섹션 8) · *캔버스 외*
미사용: miniIcon(작은 기체 마크).
- **favicon + 타이틀/메뉴 로고 마크**(캔버스가 아닌 자연 위치). HUD는 DOM이므로 캔버스 매핑은 부적합.

## 실행 순서 권장
1. **G1 (효과)** — fairness 무관, 즉시 가능, 체감 주스 큼.
2. **G2 (텔레그래프)** — 표시 전용, 가독성 향상.
3. **G3/G4/G5** — 시드 영향(버전 시프트 1회씩), design→plan→subagent 실행 + rng-fairness/perf 감사.
4. **G6 (miniIcon)** — 마무리(favicon/로고).
