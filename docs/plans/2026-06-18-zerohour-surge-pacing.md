# 스펙: Zero Hour — Surge Director + HEAT 페이싱 시스템

- **날짜**: 2026-06-18
- **상태**: 📝 설계 승인 — 구현 계획 대기
- **결정(브레인스토밍)**: 우선순위 = **페이싱(강약 리듬)** · 모델 = **서지 리듬** · 서지 내용 = **안무 포메이션(신규 적 없음)** · 보상 레이어 = **HEAT 배율(위험-보상)**

## 문제

현 Zero Hour는 "단순하고 60초가 길게 느껴진다". 구조적 원인:

1. **난이도 곡선이 거의 평평** — 기뢰 속도 `62 + t*1.1`(60초≈128), 스폰 램프도 60초 안엔 1.0→0.58뿐. 긴장 고조가 없음.
2. **40초간 위협이 기뢰 하나뿐** — 바위는 정지물. 순간 변화가 적음.
3. **런 안에 중간 목표·국면 전환이 없음** — 평평한 점수 누적, 유일 이벤트가 40초 보스.
4. **자동 사격이라 전투가 수동적** — 능동적 판단은 이동(줍기·회피)뿐.
5. **위험-보상 긴장 부재** — 수집이 대체로 안전, 콤보 창(2.6초)도 넉넉.

→ 본질은 난이도가 아니라 **페이싱·능동적 선택의 부재**.

## 목표

60초 런을 **고요 → 서지 → 고요 → 서지 → 보스 클라이맥스** 리듬으로 재구성한다.
**새 적 엔티티·새 아트 없이** 기존 기뢰를 안무 포메이션으로 연출하고, 서지 동안 **HEAT 배율**로
위험-보상을 건다. "더 어렵게"가 아니라 **긴장과 회복의 교차 + 능동적 선택**이 목적.

## 설계

### 1. Surge Director (페이싱 엔진)

서지 스케줄을 `s.duration`에서 파생해 결정적으로 생성한다(트윅으로 duration 변경 시 자동 스케일).

- **워밍업**: 0~8초는 현재처럼 가벼운 기뢰(수집·학습).
- **필드 구간**: 워밍업 종료 ~ 보스 진입(`timeLeft ≤ 20`) 사이.
  - 서지 수 `N = floor(fieldLen / 16)` (60초 기준 필드 ≈ 32초 → **N=2**), 균등 배치.
  - 60초 예시: 서지 시작 ~t=9, ~t=25. 보스 전 회복창 확보.
- **텔레그래프**: 각 서지 1.2초 전 경고(화면 플래시 + 오디오 큐). 기존 `bossWarnT` 패턴 재사용 → `surgeWarnT`.
- **보스**: `timeLeft ≤ 20` 진입(기존 유지) = **최종 서지 = 클라이맥스**.
- **서지 1회 = 5~6초.** 서지 k(1-based)는 포메이션 `6 + 3k`마리 + 일시 기뢰 가속.
- **소강기 기본 압박 하향**: 서지 비활성 구간엔 기본 기뢰 스폰을 약간 낮춰 고요-서지 대비를 강화.

상태(`freshState`)에 추가: `surges: [{at, size, pattern}]`(시드로 사전 생성), `surgeIdx`,
`surgeT`(활성 잔여), `surgeWarnT`, `inSurge`(파생).

### 2. 안무 포메이션 (서지 내용물)

기뢰를 **새 엔티티 없이** 스크립트된 진입으로 연출. **모든 난수는 `s.rng()`**(ADR-0002 공정성).
패턴은 시드 백(bag)에서 뽑아 결정적.

- **LINE SWEEP**: 한 변에서 일렬 진입 → 가로질러 쓸고 감.
- **RING COLLAPSE**: 플레이어 주변에 원형 배치 후 조여듦(텔레그래프된 원).
- **PINCER**: 반대편 두 변에서 호(arc) 협공.

각 포메이션 기뢰는 `entryT`(예 1.5초) 동안 스크립트 궤도(직선/수렴)로 움직이고, 이후
**기존 호밍 로직으로 복귀**(코드 재사용). 새 렌더 아트 불필요(서지 기뢰는 색 틴트 정도로 구분).
포메이션 기뢰도 기존 `s.mines` 배열에 들어가되 `entryT`/`vx,vy` 필드로 진입 단계를 표현 →
배열·캡(`mines.length < 12`은 서지 시 상향 필요) 관리. 핫패스 무할당 유지(객체 형태 고정).

### 3. HEAT 배율 (위험-보상 레이어)

- 새 상태 `heat`(0): **서지 활성일 때만** 누적. 서지 중 크리스털 수집(+), 생존 시간(+소량).
- 티어 배율 `heatTier`: `×1 → ×1.25 → ×1.5 → ×2`(캡). 임계값은 튜닝 상수.
- **적용 범위**: 서지 중 획득하는 점수 전체(크리스털·콤보·파괴)에 곱.
- **피격 시 `heat=0` 리셋**(콤보 리셋과 동일 규칙 — 일관성).
- **X2 중첩**: `effMul = min(HEAT_X2_CAP, x2Mul * heatTier)` 곱연산 + 총 배율 캡(예 ×4)으로 폭주 방지.
- 비서지 구간엔 `heatTier=1`(영향 없음). 서지 종료 시 부드럽게 1로 감쇠.
- **능동적 선택**: "서지를 안전히 피할까 vs 위험 속에서 수집해 크게 벌까".

`addScore`의 배율 계산에 `heatTier` 합류. 결과 브레이크다운에 `heat` 버킷 추가
(현 버킷: crystals/combo/destruction/boss → +heat).

### 4. HUD / 결과 / 렌더

- **HEAT 미터**: 서지 중 빛나는 배율 배지(예 `HEAT ×1.5`). 비서지 시 흐림/숨김.
- **서지 텔레그래프**: 경고 배너 + 화면 가장자리 펄스(기존 boss warn 비주얼 톤 재사용).
- **서지 틴트**: 서지 활성 동안 미묘한 화면/기뢰 색 변화로 국면 전환 가독성.
- **결과 화면**: 브레이크다운에 HEAT 점수 노출.

### 5. 파일

- `js/games/zerohour/game.js`:
  - `freshState`에 surge/heat 상태 필드 추가.
  - 서지 스케줄 생성기(`buildSurges(s)` — `s.rng` 결정적).
  - `update`에 Surge Director 틱(텔레그래프·시작·종료, 포메이션 스폰).
  - 포메이션 스폰 함수(`spawnFormation(s, pattern, size)`).
  - 기뢰 업데이트에 `entryT` 스크립트 단계 분기.
  - `heat` 누적·감쇠·리셋, `addScore` 배율에 `heatTier` 합류.
- `js/games/zerohour/render.js`: HEAT 미터, 서지 텔레그래프/틴트.
- `index.html`: HUD에 HEAT 배지 마크업, 결과 브레이크다운에 heat 행.
- `css/style.css`: HEAT 배지·서지 경고 스타일.
- `README.md`: 점수표에 HEAT 배율 + 서지 설명 추가(상수 동기화 규칙).
- **신규 ADR**: `docs/adr/0010-surge-pacing-and-heat.md`(페이싱 결정 기록).

## 제약 준수

- 서지·포메이션·HEAT 트리거 난수 전부 `s.rng()` → **일일 챌린지 공정성**(ADR-0002). ✓
- 기뢰 엔티티 재사용·배열 캡·고정 객체 형태 → **60fps 핫패스 무할당**. (`performance-analyzer` 사후 점검) ✓
- HEAT는 기존 점수 경로 재사용. ✓
- **README 점수표 ↔ 상수 동기화**. ✓
- duration 트윅 시 서지 스케줄 자동 스케일. ✓ / 코어 React-free·CDN 무관. ✓
- 범위: **새 적 타입·새 아트 없음** → 중간 규모(game/render/HUD/README/ADR).

## 테스트

- **단위(node --test, 순수 로직)**: `buildSurges` 결정성(같은 시드 → 같은 스케줄), 서지 수 = `floor(fieldLen/16)`,
  duration 스케일, `heatTier` 임계 경계, 피격 시 heat 리셋, `addScore` 배율 합성(X2×HEAT 캡).
- **공정성**: 같은 데일리 시드 두 런의 서지 at/size/pattern·포메이션 좌표 동일(시드 RNG만 사용 확인).
  `rng-fairness-auditor` 에이전트로 사후 감사.
- **E2E(헤드리스, 세로)**: 런 진행 중 서지 텔레그래프→서지→HEAT 배지 점등 가시 확인(결정적 부분만).
- **정적**: innerHTML 싱크 핀 갱신, 신규 코드 React-free/IIFE, 번들 해시 동기화.
